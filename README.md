Bulk Log (GitHub Pages)

1. Create a public repo on GitHub, e.g. bulk-log.
2. Add file > Upload files, drop in index.html (and this README if you like).
3. Settings > Pages > Deploy from a branch > main / root > Save.
4. Open https://<your-username>.github.io/bulk-log after a minute.

Data is stored in the browser on each device only (no account sync outside Claude).
